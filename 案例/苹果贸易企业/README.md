# 测试案例：苹果贸易企业

两份素材**分层且不重复**：文件是**背景**，对话是**本次业务**。

## 分层

| 层级 | 载体 | 内容 | 性质 |
|---|---|---|---|
| **宏观背景** | `01_企业信息.txt` | 企业概况、产业链位置、经营条件、主要风险来源 | 描述性、长期稳定、无数字参数 |
| **本次业务** | `02_对话输入.md` | 授权比例 0.6/0.8、敞口 180 吨、期限、行情 | 可操作数字、每次不同 |

两者**不重复**：企业信息里没有任何授权比例、敞口数量、期限、行情；对话里也不复述企业背景。

## 标准答案

- 方向 = **卖出保值**（180 吨正敞口，怕跌）
- 手数 = ⌊180 × 0.6 ÷ 10⌋ = ⌊10.8⌋ = **10 手**（上限 14 手）
- 点位 ≈ 围绕 AP2612 结算价 8500

## 怎么用

1. 「企业资料」页上传 `01_企业信息.txt` → 智能体自主吸收为长期记忆（企业背景）
2. 「对话」页按 `02_对话输入.md` 顺序逐条发送
3. 观察：第 1 条是否**主动追问**；第 6 条后是否给出 **卖出保值 · 10 手**

## 命令回放

```bash
node tests/cases/replay.mjs
```

## 判读要点

| 现象 | 含义 |
|---|---|
| 手数 10 / 方向卖出 | 正确 |
| 手数 11 | 误用四舍五入 |
| 方向买入 | 把"怕跌"当成了"怕涨" |
| 第 1 条直接给结论 | 引导性不足（未按信息维度追问） |
| 回复出现"已更新记忆""请核对记忆" | 记忆维护未静默化 |
